# Совместимость и ограничения

| Параметр | v0.3.0 |
| --- | --- |
| Проверенный host | Orca 1.4.218 |
| Manifest / Plugin API | v1 / v1 |
| Manifest engine gate | `>=1.4.218` |
| Разрешения | только `workspace:read` |
| Worker | отсутствует |
| Идентичность | `local-diagram.diagram-ide`, panel `model` |
| Сборка из исходников | Node.js 22.12+ и npm |

Минимальный engine gate не гарантирует совместимость со всеми последующими версиями Orca. На новой версии отдельно проверьте загрузку manifest, consent, CSP, bridge, рендер всех шести нотаций и development reload. Переносимая проверка пакета не заменяет нативную проверку.

Панель показывает включённый при сборке JSON. `workspace:read` не даёт ей произвольного чтения файлов репозитория; активное имя проекта не доказывает происхождение модели. Нет автоматического repository scanner, chat-completion hook или привязки к произвольному focused project.

Проверенный host блокирует прямой download и не предоставляет file-save API. Кнопка скачивания диаграммы не заявляется; опубликованы готовый ZIP и статические SVG-примеры на [сайте](https://tarkue.github.io/orca-system-diagrams/).

BPMN — визуализация и неисполняемый обмен модели, не workflow engine. EPC поддерживает ограниченное XOR-представление, без AND/OR-параллелизма. Обязательные поля `rules` сохранены для совместимости данных: финансового UI и выполнения бизнес-сценариев в панели нет. Подробности: [модель](MODEL.md), [нотации](NOTATIONS.md).

Независимый проект не заявляет аффилиацию или одобрение Orca. Сторонние компоненты сохраняют свои лицензии и attribution, включая watermark bpmn.io.
