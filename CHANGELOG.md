# Изменения

## 0.3.0

- Публичная поставка нативной панели «Схемы системы» для Orca: одна модель, C4, BPMN, EPC, Sequence, ER и State.
- JSON только для чтения; сворачиваемый инспектор со списком элементов и фокусировкой выбранной фигуры.
- Пресеты и кнопки −/+, масштабирование под указателем через Ctrl/Cmd + колесо и двойной щелчок. Отдельные кнопки Fit и 100% удалены; клавиши F и 0 сохранены.
- Упаковка plugin-only ZIP с notices, метаданными и контрольными суммами; переносимая проверка пакета, статический сайт и SVG-примеры.
- Документация установки, схемы модели и обновления через штатного агента и development watcher.

Проверенный host: Orca 1.4.218, Plugin API v1. Автоматическое извлечение архитектуры, chat-completion hook и прямое сохранение файлов из панели не заявляются.

- Подготовлена установка по Git URL: корневой manifest, готовый bundle и проверка синхронизации с исходниками в CI.
